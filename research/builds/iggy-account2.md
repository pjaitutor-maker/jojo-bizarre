### Badge — Santana Badge ×4 (ไอคอนหน้ากากขนนก) · Badge Skill 3 ช่อง 4/4
📖 = "Santviento Badge ×4" ที่ทีม Jotaro Castle (Kaiju, 14 พ.ย.) ใช้กับ Iggy พอดี
- **Revival** 4/4: HP <50% → การโจมตีฮีลตัวเอง 300% DEF (CD 10 วิ)
- **Monolith** (Legendary, เพดาน 6/6): HP >40% รับดาเมจน้อยลง 28%
- **Intermediate Defense** 4/4: DEF ฐาน +15%
- ❓ หน้าจอแสดง 4/4 ทั้ง 3 ช่อง แต่ Monolith ในฐานข้อมูลสูงสุด 6/6 → เช็กว่าเป็นเกรด Legendary และ Monolith ตันหรือยัง

- ❓ ระบุชื่อจากภาพไม่ได้ (ไอคอนเหมือน Badge Skill ช่องแรก) — คลัง: Inspiration 1, Damage Boost 2, Ultimate 2, Basic Attack 2, Assault 0, Mastery 0 (ทั้งหมดขึ้น Unavailable เพราะช่องเต็ม)

- 💡 ถ้าที่ใส่อยู่คือ Inspiration ×4: ฐานข้อมูลระบุ Giorno Badge "ใส่ชิ้นเดียวก็ได้ผลเซต (1/4)" → Gem ชนิดนี้ 4 เม็ดอาจไม่ซ้อนกัน

## 2. สรุป: บิลด์นี้ "ถูกทาง" แล้ว — เหลือเก็บรายละเอียด

ตรงตำรา 📖: เซต Scene ถูก · Badge ตรงทีม PvP อันดับต้น · ดาว/เลเวลชนเพดาน · Talent สายโล่/ลดดาเมจ
สิ่งที่ยังเพิ่มได้ เรียงตามความคุ้ม:

1. **หยุดลง Ability shard ที่ Iggy** (S9 → S11 ได้แค่ตัวเลข) ย้ายไปตัวที่ S1 ปลด Ultimate ที่ 2: Jotaro / Giorno / Caesar / Ermes / Bucciarati / Diavolo ([star-priority.md §1.2](star-priority.md))
2. **Scene ช่อง I–II ดันจาก +12 → +16** ให้เท่าช่อง III–IV แล้วค่อยไล่ทั้ง 4 ชิ้นไป +20 (📖 ต้อง Outstanding Lv.100 ตั้ง Favorite ด้วย Camrecorder; ย้ายค่าอัปไปชิ้นใหม่ไม่เสีย 100%)
3. **Spirit Power: เปลี่ยนชิ้นม่วง Superior ก่อน** → เป้า Outstanding VI ×3 เพื่อ Realm Bonus; reshape talent ให้ได้ Shield Bonus / DMG Reduction / Block Rate (💡 เลี่ยง talent สายโจมตีเพราะทุกสกิลของ Iggy สเกลกับ DEF)
4. **Scene ช่อง I ค่าหลัก Attack** — 📖 แท็งก์ควรเลือก base DEF/HP; ถ้าช่อง I ในเกมมี DEF ให้เลือก ควรเปลี่ยน (❓ ถ้าช่อง I ล็อก ATK เสมอ ข้ามข้อนี้)
5. **เช็ก Gem**: แตะ Gem 1 เม็ดดูชื่อ — ถ้าไม่ใช่สายป้องกัน พิจารณา Secco (ถ้า Iggy นับ Melee) หรือ Gem ที่ให้ DMG Reduction
6. **Monolith ให้ถึง 6/6** ถ้ายังไม่ตัน (ลดดาเมจ 28% ช่วง HP >40% เป็นสกิลที่แรงที่สุดในชุดนี้)

## 3. ทางเลือก Badge: Santana vs Iggy Badge 📖
| | Santana ×4 (ที่ใส่อยู่) | Iggy Badge ×4 (Hideout endgame) |
|---|---|---|
| จุดเด่น | **Iggy เองตายยาก**: ลดดาเมจ 28% + ฮีล 300% DEF ตอนต่ำ | **ทีมตายยาก**: โล่ 160% DEF ให้คนที่ HP% ต่ำสุดทุก 3 วิ; Mythic เพิ่ม *Covenant* (ผูกกับตัว ATK สูงสุด แบ่งรับดาเมจ 20% + Basic Attack +20% ให้คู่) |
| เหมาะกับ | Arena ที่ Iggy เป็นด่านหน้าตัวเดียว / ทีม Jotaro Castle | ทีมที่มี Jotaro เป็นแครี่และต้องการให้ Jotaro ยืนนานขึ้น (Covenant) |
ยังไม่พบแหล่งที่เทียบสองชุดนี้ตรง ๆ — ชุดปัจจุบันใช้ได้ ไม่ต้องรื้อ
